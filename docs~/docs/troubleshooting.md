# 困ったときは

## メニューが無い

`Tools > Poyo's Editor Toolbox` が無いときは、パッケージが入っていないか、コンパイルエラーで読み込まれていません。Console にエラーが出ていないかを確かめてください。

## 入れたのに何も起きない

最初は、どの機能もオフです。`Tools > Poyo's Editor Toolbox > Preferences…` で、使う機能をオンにしてください。

## 機能がオンかオフか分からない

`Tools > Poyo's Editor Toolbox > Project Settings…` を開いてください。チェックは、このプロジェクトで使っている値です。青やオレンジの行は、このプロジェクトだけ上書きしている項目です（[このプロジェクトだけ変える](settings.md#override)）。

## 全体設定を変えたのに、このプロジェクトで変わらない

その項目を Project Settings で上書きしています。Project Settings のその行の「全体設定に戻す」を押してください。

## 完了通知が来ない

| 確かめること | 場所 |
|---|---|
| 「時間のかかる処理が終わったら知らせる」がオンか | 設定画面の「完了通知」 |
| その処理の「音」「Webhook」がオンか | 同じ表。Play モードとインポートの Webhook は最初はオフです |
| 「知らせる最短の時間」より長くかかったか | Play モードとインポート・コンパイルは、早く終わると知らせません |
| 「テスト送信」が届くか | 届かないときは URL を確かめてください。Console に理由が出ます |

詳しくは[完了通知](notifications.md)を見てください。

## Hierarchy のチェックボックスがほかのボタンと重なる

Project Settings の「右端からの距離」を大きくしてください（[Hierarchy のチェックボックス](hierarchy.md)）。

## EditorOnly のチェックボックスが押せない

その行には `Untagged` と `EditorOnly` 以外のタグが付いています。元のタグを消さないため、押せないようにしています。

## Variant の名前に「Variant」が残る

- 元の Prefab と同じフォルダに作ると、同じ名前のファイルがあるので名前を変えません。
- 作るときに名前を入力したときは、その名前のままにします。
- 前からある Variant は変えません。

詳しくは [Prefab Variant の名前](variant.md)を見てください。

## シーンを開くたびに確認が出る

変換したあとにシーンを保存していないと、次に開いたときも確認が出ます。変換したら保存してください。変換したくないシーンでは、「このシーンでは確認しない」を選んでください。

## 変換したシーンを元に戻したい

Lighting の設定は Undo で戻りません。保存する前なら、保存せずにシーンを開き直すと戻ります（[シーンのライティング](scene-lighting.md#undo)）。

## SDK に名前やサムネイルが入らない

| 確かめること | 内容 |
|---|---|
| VRChat SDK - Avatars 3.10.0 以降が入っているか | 設定画面の項目が灰色なら、SDK がありません |
| 設定画面でオンか | 「VRChat SDK に名前とサムネイルを自動入力する」 |
| 初めてアップロードするアバターか | 一度アップロードしたアバターでは何もしません |
| 欄が空か | 自分で入れた値は上書きしません |

## サムネイルが灰色だけになる

Scene ビューにアバターが映っていないか、Scene ビューのスカイボックスが非表示です。Scene ビューにアバターを映してから、SDK の画面でアバターを選び直すか、サムネイルの欄から撮り直してください。

## ブレンドシェイプを 100 より大きくできない

[ブレンドシェイプのスライダー](blendshape-sliders.md)の「上限」を上げてください。それでも反映されないときは、Player Settings の Clamp BlendShapes がオンになっています。

## 距離クリッピングキャンセラーのチェックが押せない

| 確かめること | 内容 |
|---|---|
| Play モードではないか | Play モードの間は切り替えられません |
| lilToon 2.0.0 以上が入っているか | lilToon の節のチェックが灰色なら、lilToon がありません |
| lilToon の設定をロックしていないか | lilToon の設定画面でロックを外してください |
| Poiyomi のマテリアルが `Assets` にあるか | 無いときは「Assets に Poiyomi のマテリアルがありません。」と出ます |

## Poiyomi のマテリアルが変わらない

| 確かめること | 内容 |
|---|---|
| 除外リストに入れていないか | 除外したマテリアルは、行の `ON` で切り替えます |
| 親の値に従う Material Variant ではないか | 親のマテリアルを切り替えると、一緒に変わります |
| ロック中で、ThryEditor 2.74.3 以上が入っていないか | Poiyomi のロックを解除してから、もう一度切り替えてください |
| あとから入れたマテリアルではないか | `再スキャン` を押してから、もう一度切り替えてください |

詳しくは[距離クリッピングキャンセラー](clipping-canceller.md)を見てください。

## Irodori Colorizer の色が付かない

| 確かめること | 場所 |
|---|---|
| 単体版の Irodori Colorizer が入っていないか | 入っている間は、このパッケージの色付けを止めます |
| 「Irodori Colorizer を使う」がオンか | [設定画面](settings.md) |
| 「Project ウィンドウ」「Hierarchy ウィンドウ」がオンか | [Irodori Colorizer の設定](colorizer-settings.md)の「表示」 |
| ラベルを非表示にしていないか | 同じページの「ラベル一覧」 |
| ラベルのプリセットがオフになっていないか | 同じページの「プリセット」 |

Console に「シーンを保存してから…」と出たときは、シーンを保存してから、もう一度ラベルを付けてください。

## Project ウィンドウの行が暗いまま

[色で絞り込む](colorizer-filter.md)を使っています。右クリックの `Poyo's Editor Toolbox > Clear Label Filter` でやめてください。

## 報告する

[GitHub Issues](https://github.com/Poyotoron/Editor-Toolbox/issues) に送ってください。Unity のバージョン、Console に出たメッセージ、何をしたときに起きたかを書いてもらえると調べやすくなります。
