# 色の付き方

色をどこに記録しているかと、色が消える条件です。

## 記録するもの

色は、フォルダ名やパスではなく、対象を指す ID に記録します。フォルダを移したり名前を変えたりしても、色は残ります。

| 対象 | 記録する ID | 移動・名前の変更 |
|---|---|---|
| フォルダ、アセット | アセットの GUID | 色は残ります |
| シーンの Prefab インスタンスのルート | 元の Prefab アセットの GUID | 色は残ります |
| そのほかの GameObject | シーンの中での ID | シーンの中で動かしても残ります |

## Prefab の色

シーンの Prefab インスタンスの色は、元の Prefab アセットに記録します。Project ウィンドウと Hierarchy は同じ記録を見ているので、どちらで付けても同じになります。

| 操作 | 結果 |
|---|---|
| Hierarchy で Prefab インスタンスに色を付ける | Project ウィンドウの元のアセットにも同じ色が付きます |
| Project ウィンドウで Prefab アセットに色を付ける | シーンのすべてのインスタンスにも同じ色が付きます |
| どちらかで色を外す | もう一方からも消えます。確認のダイアログが出ます |

入れ子の Prefab では、いちばん内側のインスタンスのルートに付きます。子のオブジェクトには付きません。

## シーンの保存

Prefab ではない GameObject の ID は、シーンを一度保存するまで決まりません。保存していないシーンでラベルを付けようとすると、Console に「シーンを保存してからラベルを設定してください」と出て、色は付きません。シーンを保存してから付けてください。

## 色が消える・付かないとき

| 操作 | 色 |
|---|---|
| フォルダやアセットを移す、名前を変える | 残ります |
| GameObject をシーンの中で動かす、名前を変える | 残ります |
| アセットを削除して、同じ名前で入れ直す | 消えます。別のアセットになるためです |
| GameObject を削除して作り直す | 消えます |
| Prefab ではない GameObject を別のシーンにコピーする | コピーしたものには付きません |
| プリセットをオフにする、ラベルを非表示にする | 出なくなります。戻すとまた出ます |
| 自分で作ったラベルを削除する | 出なくなります |

## 表示

- Prefab の編集モードで開いた中身には、シーン用の色は付きません。
- Project ウィンドウのアイコン表示では、セルに色を重ねます。サムネイルと名前の位置は変わりません。
